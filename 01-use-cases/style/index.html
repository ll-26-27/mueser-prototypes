Two tools working

Style & documents

Make recurring document work easier while keeping your own form: the handout, the CV, the article and its notes.

The CV tool and the journal-style tool work and have been run on synthetic documents only. The next step is to run each on one of yours. Handouts and the footnote checker are scoped, not built.

CV

Add an entry as a line of text. It is written into a copy as a duplicate of the neighbouring entry’s paragraph, so indents, tab stops and fonts stay yours. Working; run on a synthetic CV.

Read the guide →

Journal house style

Give it a few recent articles from the journal. It counts the journal’s conventions, lists where your draft differs, and writes the changes you accept into a copy. Working; run on synthetic files.

Read the guide →

Handouts

Infer a house style from existing examples, apply it without changing the words, and update course details for a new term. Planned.

Read the brief →

Footnotes & bibliography

Find inconsistent citations and unmatched short forms. Review proposed fixes before applying them to a copy. Planned.

Read the brief →

What you bring

Your current CV as a Word file. For a submission, your draft as a Word file and three or more recent articles from the journal. For the planned tools, three to five handouts and a chapter or manuscript.

What comes back

A new copy of the document plus a report of what changed and what was refused. Your original file is never written to.

A document, a rule, a reviewable change

The CV and journal-style tools follow this workflow now; the desktop app can run their commands for you. These pages do not edit a Word document themselves.

Workflow diagram · available offline
  1. Start with the actual document and its reference examples or written style rules.
  2. Formatting and explicit checks run in code. A model is optional, for restyling citations after a journal’s examples; each of its answers is a proposal, with any word it added named.
  3. Review the report, then write an updated copy and inspect the differences.
