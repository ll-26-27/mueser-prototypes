Notes apparatus

Gather the fragments of research in one place, then find them again by project, theme, person or time.

The workflow is scoped. Importers, the database and the reviewer page still need to be built and tried with your material.

What you bring

Email exports, a few voice notes, text or Word notes, PDF highlights and reference-manager exports. Start with your project list and the themes you already use.

What comes back

A local collection with each item’s source intact, suggestions for project and theme tags, a review queue, and a digest for each project.

From scattered notes to a project collection

Planned workflow. A note may belong to more than one project; that should not create competing copies of the source.

  3. Review the suggestions, record decisions, and export the accepted collection by project.
