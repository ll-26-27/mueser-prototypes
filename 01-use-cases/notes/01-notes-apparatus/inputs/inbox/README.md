# Inbox

Drop files here, by kind: `email/` (`.eml`, `.mbox`), `voice/` (`.m4a`,
`.mp3`, `.wav`, `.ogg`), `text/` (`.md`, `.txt`, `.docx`), `pdf/` (with
highlights and notes), `zotero/` (CSL-JSON, BibTeX or Zotero RDF exports).
`notes ingest` copies each file once into `outputs/store/raw/` by its hash
and never moves or changes what is here. A file it has already seen is
skipped and reported. Nothing in this folder is committed.
