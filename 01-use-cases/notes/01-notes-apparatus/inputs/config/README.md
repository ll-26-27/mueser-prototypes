# Config

`projects.yml` is the controlled list of projects (id, name, aliases, the
codes or words that appear in subject lines, active dates). `themes.yml` is
the controlled vocabulary; it grows only by proposals accepted in the
review page. `rules.yml` holds the recorded auto-accept rules, each with an
id that is written on every row it accepts. All three start empty and are
agreed with Ben from what the first ingest brings in.
