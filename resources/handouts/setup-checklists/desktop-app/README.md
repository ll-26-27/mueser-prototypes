# Desktop app setup

Use the track for the app you have. The workshop prompts and folder structure
are the same in both; button names, available models, and approval prompts may
differ by version, plan, and institution.

## Before you begin

1. Sign in with the institutionally approved account for your chosen app.
2. Download and unzip `eng298ai-20261103` into a folder containing only the
   workshop files.
3. Identify the account, its data-handling terms, and the files the app
   will receive. The examples use the supplied workshop collection.

## ChatGPT Desktop

1. Open the ChatGPT desktop app.
2. Start a local workspace or folder-based task and select the unzipped
   `eng298ai-20261103-main` folder. The exact label may vary by app version.
3. Review the requested permissions and limit access to that folder.
4. Ask `What's in here?` and confirm the response mentions `01-use-cases`,
   `02-your-project`, `context`, and `resources`.
5. Continue with the use cases in [`01-use-cases/`](../../../../01-use-cases/README.md).

If your ChatGPT app does not offer local folder access, use its coding workspace
or Codex surface if your account provides one. Otherwise, upload only the files
needed for a particular step; file-writing steps will not behave exactly like
the workshop demonstration.

## Claude Desktop

1. Open Claude Desktop and switch to **Cowork**.
2. Choose **Add folder**, select `eng298ai-20261103-main`, and approve access
   to that folder.
3. Ask `What's in here?` and confirm the response mentions `01-use-cases`,
   `02-your-project`, `context`, and `resources`.
4. Continue with the use cases in [`01-use-cases/`](../../../../01-use-cases/README.md).

For a longer Claude-specific Cowork guide, see
[`claude-cowork-setup.md`](claude-cowork-setup.md).

## In either app

- Watch which files the assistant reads and changes.
- Set folder access to the project you are working on.
- Keep originals in `inputs/`, reusable instructions in `operations/`, and new
  files in `outputs/`.
- Keep source links and checks alongside the outputs.
